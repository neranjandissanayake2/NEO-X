NEO-X ULTIMATE

1. Backup your previous NEO-X folder and export custom study lessons / paper links before replacing.
2. Extract the ZIP to a new folder. Do not run from inside ZIP.
3. Open index.html with VS Code Live Server for Study, Gaming and 3D Viewer.
4. For NEO AI hybrid API use your previously trusted local PowerShell server at http://127.0.0.1:8765/ . Live Server cannot handle /api/neo-ai.
5. If Windows Smart App Control blocks downloaded .bat/.ps1 scripts, DO NOT disable protection. Use VS Code Live Server instead.
6. 3D engine loads Three.js from CDN and requires internet; browser games open external websites. ETS2 and ATS are paid PC games, not free browser games.
7. NEO-X is a local demo; login is not secure authentication. Never enter real passwords.
8. All existing Study/AI/Tools/Cinematic Video player scripts remain in index.html.
